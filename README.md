# consumer-behavior-analysis
End-to-end consumer behavior analysis using Python, SQL, and Power BI
📊 Overview

This project analyzes consumer purchasing behavior using Python, SQL, and Power BI to derive actionable business insights.

🛠️ Tools Used
Python (Pandas, NumPy, Scikit-learn)
MySQL (SQL)
Power BI (DAX, Dashboard)

🔍 Key Features
Data cleaning and preprocessing
Customer segmentation using K-Means clustering
SQL-based data analysis
Interactive Power BI dashboard

📊 Key Insights
High-income customers spend ~15% more
Mixed channel customers show highest spending
Frequent buyers dominate customer base
